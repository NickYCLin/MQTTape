# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting feature for this repository instead.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Do not include real broker credentials, private certificates, or
captured production payloads.

## Supported versions

Until MQTTape reaches 1.0, security fixes are provided for the latest release.
